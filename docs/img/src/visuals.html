Why it's cheap

Every agent type fixes its model, effort and a short tool list in its own file, so it starts with ~20k tokens of context, not ~80k. The coordinator's context is re-read on every request, so it stays thin. studio-core adds about 1,240 tokens to a session; the rest loads only when used.

Optional plugins

Byte budgets for CLAUDE.md, skills and agents, a moved-text checker, a per-run token report.

Scheduled "wake-up" runs: a task queue, a journal, a run lock, a usage guard and a permission gate.

Where it came from · one month of scheduled runs

Same $200 plan, same reviews: a finished task went from $33 to $6.90

The project this kit was pulled out of ran every few hours, up to 4 tasks per run, each planned, built and reviewed twice by subagents. What changed was which model ran each role, at what effort, and how much context each agent carried.
